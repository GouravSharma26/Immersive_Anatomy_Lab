**Project:** Immersive Anatomy Lab

## 1. Executive Summary & Cost Analysis

This guide provides instructions for deploying the **Dr. Nova AI Tutor & RAG Backend** to Render. The service powers anatomy question-answering, textbook RAG retrieval, and speech synthesis for both Meta Quest Standalone VR and Windows Desktop.

### Plan Comparison:
1. **Render Free Tier ($0/month):**
   - **Specs:** 512 MB RAM, 0.1 CPU core, shared IP, HTTPS provided automatically.
   - **Cold Start Limitation:** The free instance spins down (sleeps) after 15 minutes of inactivity. When a user in VR submits a question after dormancy, waking the service up takes **~45 to 60 seconds**.
   - **Recommendation:** Suitable for initial student testing and grading demos. The Unity client has been upgraded with a polite *"Waking up Dr. Nova..."* indicator to manage user expectations during cold starts.
2. **Render Starter Plan ($7/month):**
   - **Specs:** 512 MB RAM, 0.5 CPU core, always-on, zero cold starts, custom domain support.
   - **Recommendation:** Recommended for official public itch.io distribution to ensure instant, sub-second responses.

> [!IMPORTANT]
> **No Billing Authorization:** Antigravity will NOT create or provision paid cloud resources automatically. You can deploy to the Free tier first and upgrade if desired.

## 2. Step-by-Step Deployment Instructions

### Step 1: Push Repository to GitHub or GitLab
Render deploys directly from your Git repository:
```bash
git remote add origin https://github.com/<your-username>/ImmersiveAnatomyLab.git
git branch -M main
git push -u origin main
```

### Step 2: Create Web Service on Render
1. Log in to [Render Dashboard](https://dashboard.render.com).
2. Click **New +** > **Web Service**.
3. Select your repository `ImmersiveAnatomyLab`.
4. Configure service settings:
   - **Name:** `immersive-anatomy-api`
   - **Region:** Choose closest to your audience (e.g., Oregon, Frankfurt, Singapore).
   - **Branch:** `main` (or `feature/phase6-openxr`).
   - **Root Directory:** Leave blank (or `.`).
   - **Runtime:** `Python 3`.
   - **Build Command:** `pip install -r backend/requirements.txt`.
   - **Start Command:** `python backend/run_backend.py`.
   - **Plan:** Free (or Starter).

### Step 3: Configure Environment Secrets
In the Render Service settings, navigate to **Environment** and add:
- `PYTHON_VERSION` = `3.11.8`
- `HOST` = `0.0.0.0`
- `GEMINI_API_KEY` = `<your-gemini-api-key>` *(Never commit this key to Git)*

### Step 4: Health Check Configuration
- In **Settings** > **Health Check Path**, enter:  
  `/health/live`

### Step 5: Copy Production HTTPS URL
Once deployed, Render assigns a public HTTPS URL:
`https://immersive-anatomy-api.onrender.com`

## 3. Storage & Ephemeral Filesystem Strategy

- **Audio Cache:** Audio files generated by speech synthesis are stored in `backend/audio_cache/`.
- **Ephemeral Disk Handling:** On Render, local filesystem storage is ephemeral (cleared upon redeployment). Because the audio clips are short educational replies cached temporarily during the conversation, ephemeral storage is completely safe. `main.py` includes automatic pruning (`clean_old_audio_cache()`) keeping the folder under 40 files / 25 MB.
- **RAG Corpus:** Immutable medical textbook chunks are compiled into `backend/rag_engine.py`, guaranteeing zero external database dependencies.
